# Iconos PWA

Este directorio debe contener los iconos para Progressive Web App.

**Archivos requeridos:**
- `icon-192x192.png` - Icono principal (192x192)
- `icon-512x512.png` - Icono grande (512x512)

**Para generar iconos:**
1. Diseña un logo o icono para MultiCatálogo
2. Exporta en formatos PNG en los tamaños especificados
3. O usa herramientas como:
   - https://realfavicongenerator.net/
   - https://www.pwabuilder.com/imageGenerator/

**Colores sugeridos:**
- Primario: #4f46e5 (indigo)
- Fondo: #ffffff (blanco)
